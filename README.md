# SEO-аудит и конкурентное исследование pinskdrev.ru, сентябрь 2026

«Пинскдрев»: белорусская мебель, интернет-магазин и сеть из 328 фирменных магазинов в России.
Аудит собран 16.09.2026 из восьми источников: обход сайта (2 190 адресов), Playwright, Firecrawl,
PageSpeed Insights, Keys.so (Москва, Google, семь региональных баз, история 18 месяцев), Arsenkin
(ИКС, живая выдача Яндекса и Google по 25 запросам, индексация, ответы Алисы), Wordstat, WordKeeper.

Страница: https://takedown-desing.github.io/pinskdrev-seo-audit-2026-09/

Главное: видимость в Москве упала на 54 процента за 17 месяцев при росте числа страниц, по общим
категорийным запросам сайта нет в ТОП-10 Яндекса, брендовый спрос перехватывают два дилера, в технике
www-зеркало отдаёт 500, карта сайта содержит 67 вложенных индексов и 91 битый адрес, региональных
поддоменов-клонов 67. Стратегия на 6 месяцев из 25 пунктов в третьей части отчёта.

Страница закрыта от индексации.
